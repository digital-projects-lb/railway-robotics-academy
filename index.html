Robotics & Engineering Foundations

Smart trains follow a 3-carriage loop (Input → Brain → Output) every second without human common sense.

👩🏾‍🏫 2-Min Mini-Lecture: What is an Algorithm?
  • Plain English: "An algorithm is simply a step-by-step recipe of instructions. Making toast is an algorithm: 1. Put bread in toaster, 2. Push lever down, 3. Wait for pop, 4. Spread butter."
  • Why order matters: "If you do step 4 before step 1, it doesn't work! Computers follow recipes in exact order and cannot guess what you meant."
  • Practical intro: "Today I am a robot with zero common sense—you have to give me the exact recipe to pick up that cup!"

Part 1: The "Literal Train" Game (25 mins)

  • One person is a steam train with zero common sense.
  • Give exact commands: "Chug forward 3 steps", "Turn right", "Open hand", "Apply brakes".

Part 2: Household Sensor Hunt (20 mins)

Guess the Input → Brain → Output for these 3 everyday machines, then tap each button to check your answer:

🚪 Automatic Shop Door:
1. Input: Motion sensor above the door spots movement.
2. Brain: Door controller decides someone is walking up.
3. Output: Electric motor slides the glass doors open!
🧊 Fridge Door Light:
1. Input: Door-pin switch pops out when you open the fridge.
2. Brain: Electrical circuit closes automatically.
3. Output: Inside light globe switches on!
🍞 Pop-Up Toaster:
1. Input: Lever pushed down + heat/timer sensor reaches toast time.
2. Brain: Timer release latch triggers.
3. Output: Spring pops the toast up and turns off the heat!

💡 Hints

Week 3 • 45 Mins • Guide

Electricity & Complete Circuits

Electricity flows around a closed wire loop—just like a train running around a circular railway track!

👩🏾‍🏫 2-Min Mini-Lecture: What is Electricity?
  • What it is: "Electricity is the flow of tiny invisible particles called electrons zooming through metal wires—just like water flowing through a garden hose."
  • 4 Key Parts: 1) Battery (the pump pushing electrons), 2) Wires (the pipes), 3) Switch (a tap that opens or breaks the circle), and 4) Light Globe / Motor (the part that does the work!).
  • Golden Rule: "Electrons only move in a complete circle from + back to -."

Part 1: 3 Golden Rules of Electricity (25 mins)

  • Closed Loop: If a wire breaks anywhere, the light globe goes out immediately.
  • Conductors vs. Insulators: Copper & foil let electricity flow; plastic & rubber block it safely.
  • Resistors: Slow down electrical pressure (Voltage) so tiny bulbs don't blow!

Part 2: Conductor or Insulator Game (20 mins)

Look around the room and name 3 Conductors (metal spoon, coins, foil) and 3 Insulators (wooden ruler, rubber eraser, plastic cup).

💡 Hints

Safety First: Never touch wall power points—engineers only test circuits using small batteries or safe screen simulators!

Complete Circle = Power Flows!

Electricity travels from +, heats the filament inside the globe, and returns to -.

How AI "Learns" (Sound Recognition)

Regular code follows strict rules. Artificial Intelligence (AI) learns from examples—just like learning the difference between a green signal and a red signal!

👩🏾‍🏫 2-Min Mini-Lecture: How AI Differs from Regular Code
  • Regular Code vs. AI: "In Scratch, we wrote exact rules. With Artificial Intelligence (AI), we don't write rules—we show the computer lots of examples and let it spot patterns on its own!"
  • How Audio AI hears: "The computer turns your clap into a sound-wave picture and compares it to the examples you recorded."
  • Quiz Answer: "B is correct—AI only knows what we show it during training!"

Part 1: Train a Clapping Train Controller (30 mins)

  1. Open Teachable Machine (Audio) and record 8 seconds of quiet room noise for Background Noise.
  2. Create two classes: "Clap = GO" and "Tap Table = STOP", and record 8 samples of each!

🚗 Project 1: Autonomous Lane-Keeping Car (Like a Tesla)

1. INPUT: Front bumper colour sensors detect white road lines.
2. AI BRAIN: If/Then steering rules keep the car inside the lane.
3. OUTPUT: Left/right wheel steering + automatic red-light braking.
  1. Draw the Road: Paint a black looping track in Scratch with bright white edges and a red stop line.
  2. Paint Bumper Sensors: Draw a top-down car with a yellow dot on its front-left bumper and a blue dot on its front-right bumper.
  3. Code Auto-Steering: Inside a forever loop, add move (3) steps. Then add: if <colour [yellow] is touching [white]?> then turn right (5) degrees (and turn left when blue touches white!).
  4. Add Red-Light Stop: Add if <touching colour [red]?> then wait (2) seconds so it obeys traffic lights automatically!

🚁 Project 2: Autonomous Flying Rescue Drone

1. INPUT: Downward altitude sensor measures height above the ground.
2. AI BRAIN: Flight controller balances all 4 rotors so the drone hovers level.
3. OUTPUT: 4 spinning propeller motors + servo claw that drops a medical kit!
  1. Draw a Drone & Landing Pad: Paint a quadcopter drone sprite and a green Rescue Target pad at the bottom of the screen.
  2. Code Gravity & Hover: Inside a forever loop, add change y by (-2) (gravity!), plus if <key [up arrow] pressed?> then change y by (5) to fire the rotors!
  3. Code Auto-Landing: Add if <touching [Rescue Target]?> then say "Supplies Delivered!" and stop all scripts.

🧳 Project 3: Smart Airport Baggage Sorter

1. INPUT: Microphone hears scanner beep codes as bags move down the belt.
2. AI BRAIN: Sound AI decides whether the bag goes to Gate 1 (Sydney) or Gate 2 (Melbourne).
3. OUTPUT: Conveyor diverter arm pushes the suitcase onto the right chute!
  1. Pick 2 Scanner Sounds: Use a bell/spoon tap for "Gate 1: Sydney" and two claps for "Gate 2: Melbourne".
  2. Train the Sound AI: Open Teachable Machine (Audio), record 8 samples of each sound, and click Train Model.
  3. Sort the Suitcases: Play each sound as you slide toy bags across the table and see if the AI routes them to the right flight!

🤖 Project 4: 6-Wheeled Footpath Delivery Rover

1. INPUT: Front ultrasonic "bat-ear" sensors bounce sound waves to measure distance (cm).
2. AI BRAIN: Arduino Uno checks if distance < 20 cm.
3. OUTPUT: Steers the 6 independent wheels around footpath obstacles safely!
  1. Open Tinkercad Circuits: Drag out an Arduino Uno, an Ultrasonic Distance Sensor (HC-SR04), and two DC Motors.
  2. Wire Power & Pins: Connect sensor VCC to 5V, GND to GND, and signal pins to Digital Pins 7 and 8.
  3. Code Obstacle Avoidance: In Tinkercad's block/text editor, program: if (distance < 20) → stop left wheel motor so the rover steers smoothly around the obstacle!

🧩 Scratch — Visual Block Coding

Scratch lets you snap colourful code blocks together like interlocking bricks to control trains, cars, and drones without worrying about typing typos.

Key Concepts You Learn Here

  • Events (Yellow): Triggers like when green flag clicked or when key pressed.
  • Loops (Orange): forever and repeat blocks that keep a train checking its sensors.
  • Conditionals (Orange): if / then blocks that let a train decide when to brake!
  • Variables (Dark Orange): Memory boxes that track Passengers, Speed, or Coal.

Home Saving Tip: Click File → Save to your computer to save a .sb3 file without needing an account.

⚡ Tinkercad Circuits — Virtual Electronics Lab

Tinkercad lets you wire batteries, light globes, switches, motors, and Arduino microcontrollers safely on screen—so you can test circuits before building them at camp!

Key Concepts You Learn Here

  • Closed Circuits: Electricity must travel in a complete loop from + back to -.
  • Polarity: LEDs have a long/bent positive leg (Anode) and a short negative leg (Cathode).
  • Resistors: Protect tiny globes and LEDs from burning out when connected to stronger batteries.
  • Microcontrollers: Code an Arduino Uno using blocks or real C++ text!

🎙️ Teachable Machine — Audio Pattern Recognition

Teachable Machine is a free web tool that lets you train a real Machine Learning model using claps, whistles, or table taps—no coding required!

Key Concepts You Learn Here

  • Training Data: Recording 8+ sound samples for each category ("Class").
  • Pattern Recognition: How AI spots rhythm and pitch differences between claps and taps.
  • Confidence Score: The percentage bar (0–100%) showing how sure the AI is about what it hears.
  • Local Processing: Everything runs right inside your web browser.
